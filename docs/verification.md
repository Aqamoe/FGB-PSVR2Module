# 真机验收清单

> 当前状态：**未验证**。下列任一项完成后，请在 issue 里附设备与版本信息
> （PSVR2 Toolkit 版本、DriverEx 版本、宿主版本）。

## 环境

| 项 | 值 |
|---|---|
| 硬件 | PSVR2 头显 + PSVR2 摄像头标定 |
| 驱动 | PSVR2 驱动 + PlayStation VR2 Toolkit（记录版本号） |
| 系统 | Windows 10 / 11 x64 |
| 宿主 | FaceGaze Bridge（记录版本号） |

## 步骤

- [ ] Toolkit 中启用眼动追踪，DriverEx 正在运行
- [ ] PC 上关闭 VRCFT（它的 PSVR2Toolkit 模块会连同一个 3364 端口）
- [ ] FGB「模块库 → 原生模块」安装 `psvr2-<版本>.zip`
- [ ] 「模块」页把 PlayStation VR2 设为启动（角色 eyes + gaze），重启引擎
- [ ] 戴好头显，模块卡片显示活跃

## 观察项

- [ ] 眼球左右移动 → 注视方向跟随，**极化正确**（看左时 x 为负；z 轴极化是未确认项，重点核对）
- [ ] 看远/看近（vergence）→ 方向变化合理，不跳变
- [ ] 自然眨眼 → 睁眼度短暂下探后恢复；闭单眼只降该眼
- [ ] 瞳孔数据在 (2, 8) mm 区间内波动
- [ ] 摘下头显 / 未标定 → 不伪造方向（属性位缺失）或有断流提示
- [ ] 退出并重启 Toolkit/DriverEx → 模块自动重连、重新握手并恢复出帧（无需重启引擎）
- [ ] Toolkit 未启动时安装模块 → 退避重连，日志不被刷屏（首次一条，之后每 30 秒至多一条）

## 与上游对比（可选但有用）

同一台机器并用 VRCFT 的 PSVR2Toolkit.VRCFT 模块，对比 `Eye.Gaze` 与
`Openness`、`PupilDiameter_MM` 曲线。特别是注视方向的 x/z 符号：若本模块显示
「映射后不朝 -Z」告警，说明服务端的 z 极化假设反了，请把日志一并提交 issue。
